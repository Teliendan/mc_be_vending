# Changelog

Player-facing changes of each published release, newest first.

## 0.9.1 (2026-11-22)

### Fixed

- **Nether Loot Machine**: The Nether Loot Machine recipe now needs red nether bricks in the middle instead of a nether wart block. Nether wart blocks also grow in crimson forests, so they did not prove a fortress visit; red nether bricks need nether wart, which only grows in fortresses and bastions.

## 0.9.0 (2026-11-22)

### Initial release

First release of Vending Machines.

- **Core** (required): every machine pack needs it, and turning it on also turns on the Resource Pack. It adds the Upgrade Kit: use one on a machine to lower its prices.
- **Villagers**: a machine for each villager profession: Armorer, Butcher, Cartographer, Cleric, Farmer, Fisherman, Fletcher, Leather Worker, Librarian, Shepherd, Stone Mason, Tool Smith and Weapon Smith. Use them in place of a villager trading hall.
- **Wandering Trader**: one machine that keeps the wandering trader's trades available all the time, so you no longer wait for him to show up.
- **Shulker**: a machine that sells shulker shells and shulker boxes. There is no shortcut to it: its Shulker Core is crafted from nine shulker shells, so you need to fight shulkers first.
- **Loot**: four Loot Machines (Overworld, Nether, Trial and End) sell mob loot such as bone, blaze rods and nether stars. They are made for Peaceful worlds, where those mobs never appear, and also save you from farming mobs. A Peaceful world is meant to use the other machine packs too.
