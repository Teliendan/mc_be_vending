> **Test build.** This is a pre-release for testing. Things may still change before the public release, so back up any world you care about. Feedback is welcome.

Vending Machines adds craftable machines that trade like villagers, the wandering trader and a shulker, or sell mob loot. Place one and trade with it like with a villager.

The add-on comes as several behavior packs, so you can turn on only the machines you want. The .mcaddon imports them all; in a world's Behavior Packs settings, turn on Core plus the machine packs you want. Each machine pack needs Core, but none needs another.

It works on its own and needs none of the author's other add-ons.
