Vending Machines adds craftable blocks that trade like villagers, the wandering trader, a shulker and mob loot. You place one down and trade with it.

The add-on comes in modules. Turn on only the machines you want:

- **Vending Machines — Core** (required): the shared scripts and the Upgrade Kit.
- **Vending Machines — Resource Pack** (required): textures, models and names for every machine. Core lists it as a dependency, so Minecraft normally turns it on together with Core. If machines look wrong, turn it on yourself.
- **Vending Machines — Villagers**, **Vending Machines — Wandering Trader**, **Vending Machines — Shulker** and **Vending Machines — Loot** (optional): one machine group each. Each needs Core, but none needs another.

The .mcaddon imports all of these packs at once. When you create or edit a world, open its settings and turn on the packs under Behavior Packs and Resource Packs. Pick Core and each machine pack you want in Behavior Packs, and the Resource Pack in Resource Packs if it was not added for you.

It works on its own and needs none of the author's other add-ons.
